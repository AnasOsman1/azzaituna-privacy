# Azzaituna app: privacy policy

The public privacy policy of the Azzaituna app (Centro culturale islamico
Azzaituna - l'Olivo, Trento), published with GitHub Pages at
https://anasosman1.github.io/azzaituna-privacy/

The page is `index.html`. Keep this address stable: it is entered in the
Google Play Console and printed in the store listing. When the app changes how
it handles data, update the page and its "Last updated" date before the new
version reaches the store.
